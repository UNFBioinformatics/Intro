Penguins R Data

Introduction

The palmer penguins are a set of penguins inhabiting an Antarctic Penninsula called the Palmer Archepelago. The penguins were wild and inhabited the islands near Palmer Research Base and Anvers Island. The data set defines bill length, bill depth, flipper length, weight, sex, and the location they were found at of 3 species of penguins.

# We will put the males, females, and NA penguins into seprate data packages. 
pmale <- penguins[which(penguins$sex == "male") ,]
pfemale <- penguins[grep("female",penguins$sex) ,]
pSexNA <- penguins[is.na (penguins$sex) ,]

Figures

The following figures represent the characterisitcs that destinguish the sexes of each penguin which is size, and the species on each island. Figure 1 is a jitter plot.

pSexes <- rbind(pmale, pfemale) 
ggplot(pSexes, aes(x = sex, y = body_mass_g, color = sex)) +
geom_jitter(width = 1, height = 1, alpha = 1.0, size = 1) + theme_minimal()

Figure 1. Penguin sexes vs body mass in grams. Males seem to fall into the larger end of the dataset, while females seem to be smaller. This suggests sexual dimorphism, but all species are plotted together.

Figure 2 is counting plot, and represents the amount of species on each island.

plot_data <- bind_rows(pmale, pfemale)
ggplot(plot_data, aes(x = species, y = island, color = species)) +
geom_point( position = position_jitter(width = 0.2, height = 0.2), shape = 2, size = 1, stroke = 0.8) + labs(x = "Species", y = "Island",) + theme_minimal()

The graph suggests that Chinstrap and Gentoo penguins are endemic in this archepelago to Dream and Biscoe island respectively.
