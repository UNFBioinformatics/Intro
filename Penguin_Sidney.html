Introduction

The Palmer Penguins dataset contains measurements of three penguin species from islands near Palmer Station in Antarctica. The data includes things like bill length, bill depth, flipper length, and body mass. I want to explore questions like how many penguins there are, how males and females differ, and how the species compare.

Data Visualization

Male vs Female Differences

This plot compares male and female penguins to see which measurements differ the most.

ggplot(penguins, aes(x = sex, y = body_mass_g, fill = sex)) +
  geom_boxplot() +
  labs(title = "Body Mass Differences Between Male and Female Penguins",
       x = "Sex",
       y = "Body Mass (g)") +
  theme_minimal() +
  scale_fill_brewer(palette = "Set2")

Species Differences

This plot shows how flipper length varies between Adelie, Chinstrap, and Gentoo penguins.

ggplot(penguins, aes(x = species, y = flipper_length_mm, fill = species)) +
  geom_violin() +

       x = "Species",

ggplot(penguins, aes(x = island, fill = species)) +
